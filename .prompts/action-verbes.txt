1. Core Action Verbs (Most Important)

	* Create / Build
		* create
		* build
		* generate
		* construct
		* initialize
		* instantiate
		* setup
		* configure

		* Example:
			* createUser
			* buildTree
			* initializeArray

	* Get / Fetch / Retrieve
		* get
		* fetch
		* retrieve
		* obtain
		* load
		* read

		* Example:
			* fetchUserData
			* getCurrentUser
			* loadConfig

	* Update / Modify
		* update
		* modify
		* change
		* adjust
		* revise
		* edit

		* Example:
			* updateProfile
			* modifySettings

	* Delete / Remove
		* delete
		* remove
		* clear
		* erase
		* destroy

		* Example:
			* deleteAccount
			* removeItem
			* clearCache

	* Add / Insert

		* add
		* insert
		* append
		* push
		* include

		* Example:
			* addItem
			* insertNode
			* appendValue

7. Clean Function Naming Formula

	* Here is a simple formula you can use:

	* Verb + Object

	* Examples:
		* calculateTotalPrice
		* fetchUserProfile
		* validateInputData
		* mergeIntervals
		* updateUserSettings

	* Never write:
		* dataProcess
		* thingHandler
		* doWork

	* Those are weak.
